# Fundamentos_py_class_objetos_y_encapsulacion


El recorrido de hoy

Empezamos con la clase Libro, donde no solo hicimos lo básico de prestar/devolver, sino que le dimos memoria: ahora el libro recuerda quién lo tiene y cuándo se lo llevó, como si fuera una ficha real de biblioteca.

Después pasamos a CuentaBancaria, un ejercicio más "serio" de encapsulación: ahí aprendiste (o repasaste) por qué a veces uno quiere que ciertos datos —como el titular de una cuenta— no se puedan cambiar así como así, y cómo Python te deja poner "guardas" (el ValueError) para que nadie meta un saldo negativo por accidente.

Y el más grande, el Sistema de Préstamos de Equipos: este fue el que más músculo tenía detrás, porque combina las tres estructuras de datos que pedía tu profesor —diccionarios para organizar todo, listas para guardar el historial, tuplas para que cada préstamo quede como un registro fijo que no se puede alterar— y además tiene un menú de verdad, con el que puedes navegar como si fuera un programita real de una universidad o empresa.

Y luego, la parte humana del asunto

Cuando me dijiste que el código no te corría en VSCode, eso también es parte normal del proceso —a todo el mundo que aprende a programar le pasa, no es que hayas hecho algo mal. Casi siempre es algo sencillo: falta la extensión de Python, o el intérprete no está bien seleccionado. Ya te dejé la guía para resolverlo paso a paso.
